HTML & CSS Practice Projects ☕💻

About This Project

This repository contains two frontend projects I built to strengthen my understanding and practical use of HTML and CSS.

Rather than only studying HTML and CSS through tutorials, I wanted to practice by building complete webpage layouts from scratch. These projects helped me turn the concepts I have learned into actual interfaces.

Projects

1. Amber & Ash Coffee House ☕

A responsive coffee shop website designed to practice creating a warm, clean, and welcoming user interface.

What I practiced:

- HTML page structure
- Semantic HTML elements
- CSS styling
- Flexbox
- CSS Grid
- Typography
- Buttons and cards
- Navigation bars
- Forms
- Hover effects
- Responsive design
- Media queries

2. Tech Company Landing Page 💻

A landing page for a technology company designed to practice creating a modern business-oriented interface.

What I practiced:

- Structuring a landing page with HTML
- Hero sections
- Navigation
- Content sections
- Call-to-action buttons
- Cards
- Flexbox and Grid layouts
- Spacing and alignment
- Typography
- Responsive layouts
- CSS styling and positioning

Purpose

The main purpose of these projects is to strengthen my HTML and CSS skills through practice and project-based learning.

These projects are part of my journey from learning individual concepts to being able to combine those concepts to build complete, responsive websites.

I am intentionally keeping the projects within the technologies I am currently learning instead of relying on advanced frameworks or unnecessary tools.

What I Learned

Through these projects, I gained more practical experience with:

- Structuring webpages using HTML
- Styling webpages using CSS
- Creating layouts with Flexbox and CSS Grid
- Making websites responsive on different screen sizes
- Organizing CSS code
- Creating reusable classes
- Working with spacing, typography, colors, and borders
- Designing cards and sections
- Creating navigation menus
- Building complete webpages instead of isolated components

Technologies Used
